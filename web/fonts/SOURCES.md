# Font provenance

Latin/ASCII subsets of Anton and IBM Plex Sans Regular/SemiBold from the canonical Rahil Design bundle, whose upstreams are [Google Fonts Anton](https://github.com/google/fonts/tree/main/ofl/anton) and [IBM Plex](https://github.com/IBM/plex). The upstream SIL OFL notice text is retained; line endings and trailing whitespace are normalized.

Subset with fontTools 4.67.0 and Brotli 1.2.0; Unicode U+0020–007E plus nonbreaking space, middle dot, typographic quotes/dashes and ellipsis. Modified font-family metadata is renamed Build Notes Display / Build Notes Body; glyph design remains Anton / IBM Plex Sans. Self-hosted WOFF2 means the demo makes no font-network request. Project code is not relicensed.
