    What a pass does not mean

    • The browser cannot reach a node, so block hash, freshness and balances are skipped, not passed. Run node src/cli.js verify <bundle> against the node for those.
    • A signature proves someone could sign for the address at signing time. It does not prove the coins were not borrowed for the snapshot.
    • The liability tree proves each disclosed leaf is counted. It cannot show that no liability was left out; only creditors checking their own leaf, and the audited balance sheet, can.
    • The BTC/USD price is an input stated in the bundle, not a market quote.
